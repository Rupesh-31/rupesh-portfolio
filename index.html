PROJECT

💊 PharmaCare Pharmacy Management System (Java)

Tech Stack: Core Java, OOP, Collections, File Handling
Type: Console-Based Application

🔹 Project Overview

PharmaCare is a Java-based pharmacy management system designed to automate medicine inventory tracking, billing, and sales management for a small-scale pharmacy. The system reduces manual errors and improves efficiency through structured data handling and logical workflows.

🔹 Key Features

Developed a menu-driven console application for managing pharmacy operations efficiently. Implemented medicine inventory management with add, update, delete, and search functionalities. Designed a billing module to generate customer bills with quantity-based price calculations. Added stock availability validation to prevent selling out-of-stock medicines. Implemented expiry date tracking logic to identify expired and near-expiry medicines. Used Java Collections (ArrayList, HashMap) for efficient in-memory data management. Applied Object-Oriented Programming principles such as encapsulation and modular design. Included file handling to persist medicine and sales data locally. Handled input validation and exception handling to ensure application stability. Followed clean code practices with readable class structure and meaningful naming conventions.
